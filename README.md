# SISTec Digital Pass

![SISTec Digital Pass App Showcase](https://img.youtube.com/vi/NrBc7qjgI5Q/maxresdefault.jpg)

**SISTec Digital Pass** is a smart, automated campus gate pass and security management system designed to streamline student outings, faculty approvals, and security checks.

## ✨ Features

- **For Students:** Apply for gate passes digitally, view status, and manage profile.
- **For Faculty/HODs:** One-click approval system with real-time notifications.
- **For Security Guards:** Dedicated console to verify passes via QR/Barcode scanning before allowing exit.
- **For Parents:** Automated SMS/WhatsApp notifications when a student leaves or enters the campus.

## 🛠️ Technology Stack
- **Web Frontend:** React, Vite, CSS3 (Glassmorphism UI)
- **App:** Android
- **Database & Backend:** Firebase / Node.js (API architecture)
